### 🎨 Magic 4rt+
- **Estado:** En desarrollo 🚧
- **Esta Funcionando:** Si
- **Descripción:**  
Magic 4rt+ es una App diseñada para artistas, donde pueden subir y compartir sus obras, ya sean pinturas, dibujos, esculturas, etc. Este proyecto destaca por su facil manejo al ser una red social para artistas, usando botones de likes, comentarios, etc.

#### Funciones en Desarrollo:
- Se esta desarrollando el modo oscuro/claro
- Chat privado entre usuarios
- Respuestas entre comentarios
- Integracion de videos y reels
- Solucion de bugs pequeños
- Mejoras de diseño
